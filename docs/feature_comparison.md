## 🏆 Where Drawly Wins

- **Dashboard & Project Organization** — Full folder system, scene grid, metadata
- **Cloud Auto-Save** — Built-in Supabase persistence (free Excalidraw uses browser storage)
- **Canvas Background Colors** — 10 preset backgrounds including dark themes
- **Dot Grid Pattern** — Visual reference grid on canvas
- **Viewport Culling** — Only renders visible elements (performance optimization)
- **JSON Export** — Raw scene data export for developers

## 🔴 Critical Gaps (High Impact)

1. **Element Resize & Rotate** — Can't resize or rotate drawn shapes
2. **Right-Click Context Menu** — No custom context menu at all
3. **Copy / Paste / Duplicate** — No clipboard operations
4. **Stroke Style (Dashed/Dotted)** — Only solid strokes
5. **Opacity Slider** — No way to adjust element transparency
6. **Fill Styles** — Only solid fill, missing hachure/cross-hatch
7. **Multi-Select** — Can only select one element at a time
8. **Layer Ordering** — No bring-to-front / send-to-back

## 🟡 Nice-to-Have Gaps (Medium Impact)

1. Image Insert tool
2. Frame Tool & Web Embed
3. Group / Ungroup elements
4. Flip Horizontal / Vertical
5. Sharp / Round corner edges
6. Custom color picker (hex input)
7. Shape library system
8. Command palette
